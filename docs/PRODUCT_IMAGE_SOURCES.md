# Product Image Sources

This document records the source of every product image used in `src/main/webapp/images/products/` that was obtained from an external, freely-usable image source. Images are stored locally (no hotlinking); `db/seed.sql` `image_url` values point only to local files.

A prior phase placed 40 images in the catalog; 18 were real photos and 22 were `placeholder.png` copies. This document lists the replacements for those 22 placeholders plus the sources used for the 18 original real images.

All files were downloaded, resized/letterboxed to 800x800 JPEG, and saved locally.
